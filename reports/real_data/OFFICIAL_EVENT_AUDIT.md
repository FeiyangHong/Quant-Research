# 官方事件与全收益基准审计

审计日期：2026-11-14。已实际保存 **23 份官方 PDF 原件（22 份基金公告／报告、1 份指数身份事实表）**、2 个上交所公告查询结果，以及中证 H00300 的 2019—2024 历史响应。结果为 **证据暂存，可审查；不是可直接运行策略的 Dataset**。没有采购、注册账户、使用用户凭证或真实下单。

结构化入口为同目录 `official_events.json`。`sources` 逐份保存原始 URL、文件路径、SHA-256、字节数、抓取时刻、文件公告日期与日期精度；`events` 保存事实日期及金额；`coverage` 区分明确无事件、已对账与尚未完整收集；`query_audits` 保存查询范围、分页计数及全部公告索引；`benchmark_audit` 保存 H00300 与交易日历的核对结果。原件在 `data/raw_official/`，未改写原始响应。

## 时间处理与可执行性

只知道公告日时，使用仓库的 `date_only_available_at()`：**公告日之后第一个交易日 21:00，Asia/Shanghai**。日历采用本次归档的 BaoStock 2019—2024 交易日标志，并在 JSON 绑定原始文件哈希。该时间是研究政策，不冒充官网原始上网时刻。2025 年公布的 2024 年报仅作事后完整性核对，`conservative_available_at=null`，角色为 `retrospective_audit_only_not_signal`；不得提前用于 2024 年信号。

所有事件均标记 `stage_only=true`、`engine_ready=false`。公告所载经济日期可以早于保守可用时刻，此时不得直接回填引擎。清算分配公告没有提供除息日或会计确认日，JSON 将这两个字段留空；2024-04-01 仅作为保守可用时刻之后的首个交易日，列作 `accounting_recognition_candidate`，明确是待审核的模型政策。投资人实际到账记录仍未取得。
