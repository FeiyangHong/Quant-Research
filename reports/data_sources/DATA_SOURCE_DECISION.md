# 数据源选择：免费优先

2026-11-14；主要统计本金已由用户确认为100,000元。本决定依据本仓库实际接口探针及官方文档，不依据供应商品牌推定数据质量。详细证据见[免费源实测](FREE_SOURCE_AUDIT.md)、[结构化服务比较](PROVIDER_COMPARISON.md)。

## 当前选择

**首先评估 BaoStock 作为免费日线数据主候选，东财/AKShare作为行情交叉检查，交易所及基金公司原始公告作为生命周期、分红与交易规则的事实依据。现在不采购付费套餐。** 这是数据获取优先级，不是宣称该组合已经通过全部M0审计。

实际探针发现：BaoStock当前版本有ETF历史接口，匿名调用可用；对510300的2023-12-01至2023-12-08六个交易日，未复权OHLC与成交额和东财一致。成交量需统一份/手的单位，不直接比较裸数。

反例同样保留：512320有官方终止上市公告，东财测试区间返回空，而BaoStock返回零量平价记录且证券主表查不到该产品。零成交和停牌不等于有真实可交易报价；今天主表缺失不允许删除这只历史产品。该例阻止把单一免费接口直接认定为无幸存者偏差的完整数据库。

## 后续准入顺序

1. 原始快照只追加：保存请求参数、返回体、采集时间、SDK版本和hash。采集时间不能伪装成历史可得时间。
2. 以官方产品上市/终止公告构建全存续ETF主表；逐产品核验基金类型、账户资格、历史跟踪指数与规则。
3. 下载截至2024年的开发/选择验证数据，与至少一个独立源按年代、产品、困难日期对账；2025以后保持隔离。
4. 逐笔补齐基金分红、拆合份额、登记/除息/到账日，构造总收益特征，同时保留原始价格用于撮合。
5. 对零量平价、缺记录、停牌、清盘期间单独标记；验证历史日历、价格限制及单位后才接入严格Dataset。
6. 明确允许的个人研究、自动抓取、存储与共享用途；接口免费或代码开源不能自动证明底层数据具备所有这些许可。

当前免费探针仍不足以通过完整生命周期、PIT和公司行为验收，故真实R1回测继续BLOCKED_DATA，不以六天样本生成Alpha结论。

## 何时考虑付费

- Tushare是结构化ETF数据的备选：主表、日线、分红、复权、日历及ETF价格限制接口可减少整合工作。官方页面的积分门槛存在不一致，以对应账号实际权限和供应商确认值为准；免费注册不承诺完整ETF数据。即使付费，仍须对退市及历史版本验收。[ETF日线专页](https://tushare.pro/document/2?doc_id=127)
- RQData优先留给后续R2财务PIT专项试验。取得试用后先验证至少20个首发/重述样本；不能把有PIT接口等同于已审计通过。[PIT文档](https://www.ricequant.com/doc/rqdata/python/stock-mod)
- JQData作为替代候选；试用日期、ETF覆盖与访问环境需要实际确认。当前不承诺试用覆盖本项目完整历史。

按10万元本金，每年1000元固定费用对应本金的1%，这是成本算术示例，不是供应商报价。只有能填补明确数据缺口、且用途与权限满足要求时再提出具体购买方案。本轮没有注册账号、购买数据或连接券商。
