# A 股 Alpha 假设登记与优先级

版本：0.1。证据检索截止：2026-11-14（Asia/Shanghai）。状态：第一阶段研究规范；本项目尚无行情实验、回测结果或可部署策略。

## 1. 本文的职责

本文维护候选收益来源、证据边界、研究优先级和终止理由。数学信号与组合参数以 [STRATEGY_SPEC.md](STRATEGY_SPEC.md) 为准；切分、试验次数预算及统计门槛以 [EXPERIMENT_PLAN.md](EXPERIMENT_PLAN.md) 为准；字段与信息可得时间以 [DATA_CONTRACT.md](DATA_CONTRACT.md) 为准；仓位和实盘边界以 [RISK_POLICY.md](RISK_POLICY.md) 为准。

下表的时间尺度是**候选研究频段**，不是授权 Codex 枚举所有窗口。只有实验计划列入的配置可以执行。新增方向、窗口、样本或特征组合应先登记，不能以探索为由绕过搜索预算。

全部候选都采用三个集合：研究集可覆盖全 A、指数与外部市场；可交易集由账户实际权限和当时证券状态确定；替代集由当时存在且合规可交易的 ETF 等工具构成。科创板和北交所的研究价值不构成其个股交易授权。代理工具的净收益必须单独回测，不得用指数历史冒充 ETF 可交易历史。

## 2. 证据分类

| 标记 | 含义 | 不能推导的结论 |
|---|---|---|

| **Research Hypothesis** | 机制有依据，但对本项目股票池、时点、费用与做多约束仍需检验 | 不能当作已通过验收的 Alpha |
| **Speculative Idea** | 数据或可复制证据不足，主要是探索性机制 | 不能使用为核心策略理由，也不能挤占已登记实验预算 |

文献编号 L01–L11 的原文链接、发布日期、样本时期和访问缺口见 [ALPHA_LITERATURE.md](../evidence/ALPHA_LITERATURE.md)。其中“已读原文”和“仅核实摘要”严格区分。所有交易规则仍应根据独立规则登记表逐日应用，不能由旧论文替代现行或历史规则核验。

## 3. 收益来源判断

首先把收益拆为市场暴露、规模／价值等风格暴露、行业配置、个股选择、动态仓位和执行成本。分解不是唯一因果解释：风险模型不完备，行业与风格可能共线，动态 Beta 还可能制造静态回归截距。归因应同时报告持仓暴露、匹配基准和预先指定的风险模型，不得只挑最有利的 Alpha 回归。

L01、L02 支持在历史 A 股样本中认真研究价值、风险与交易类信号，同时提醒质量、普通动量及其他异象并非普遍独立。L03 的大规模复制显示，微盘权重、组合断点和多重检验能显著改变发现数量。这些是研究设计的依据；它们不规定本项目必须采用某个因子，更不保证净收益。[L01–L03](../evidence/ALPHA_LITERATURE.md)

个人的小资金可以减少市场冲击，并允许不承担机构基准跟踪压力；它也面临整手约束、最低收费、数据固定成本和持仓分散不足。**容量小不是 Alpha，灵活空仓也不是已证实的择时能力。**四档资金必须分别经过可执行组合和费用检验。

| H02 盈利与质量 | 盈利持续性、现金转化及资产负债稳健可能改善选择或尾部 | L01/L02 对独立贡献结论有限；**Research Hypothesis**，不预设质量 Alpha | 月—年 | 财务压力、行业会计差异、估值过高 |

## 5. 策略研究矩阵二 实现约束

成本、容量与复杂度为初步工程判断，不是经过成交数据校准的结果。“容量较高”也不表示所有证券均适合 100 万元账户。证券容量、基金规模、可成交金额和账户最小有效持仓数须分别计算。

| ID | 必要数据 | 成本与换手预估 | 容量与约束 | 复杂度／样本外失效风险 | 个人适用性与优先级 |
|---|---|---|---|---|---|
| H01 | PIT 财务、未复权价格、公司行为、行业／规模 | 低至中 | 液态中大盘较可扩展；分散和整手影响小资金 | 中／中：会计变更、价值陷阱 | 高；R2 核心候选 |
| H02 | PIT 利润、现金流、资产负债及版本 | 低至中 | 与 H01 共用池；金融业需单独处理指标 | 中／中：定义冗余、负权益 | 高；R2 增量与风险控制 |
| H03 | 真实分红、除权、持有期税务、ETF 费率 | 低；税负另计 | 可用股票或合格 ETF；行业集中 | 低至中／中：股息不可持续 | 适合低换手对照；延后独立开发 |

## 6. 推荐四个研究方向

优先级按证据可核查程度、低成本实现、快速证伪能力、数据可靠性及收益来源互补性确定，不按想象中的收益排序。

| 方向 | 包含假设 | 第一项要回答的问题 | 启动条件 | 暂时不能做的扩张 |
|---|---|---|---|---|
| **R1 ETF 相对强弱与风险基线** | H11/H12；H14 独立开关，H13 仅在实验计划授权时扩展 | 相对排序是否优于同池静态配置？趋势开关是否独立改善风险效用？ | ETF 生命周期、基准、费用、交易资格与实际上市历史通过审计 | 同时搜索大量行业、主题、期限及风控开关 |
| **R2 低频股票排序** | H01/H02；H05/H06 仅作为预先指定控制；H19 为模型对照 | 价值加盈利质量是否在成本、风格和风险匹配后仍有增量？ | PIT 财务、历史证券池、公司行为与成交规则通过审计 | 把质量默认当 Alpha；为改善结果反复改变中性化／风险模型 |
| **R3 短期残差反转** | H09 | 严格次日可执行和成本压力下是否尚有净增量？ | 能区分信号时间、成交时间及无法退出的存量持仓 | 把跌停无法成交订单删除；偷偷回到同收盘成交 |
| **R4 PIT 事件** | H15/H16 分别登记 | 新信息在首次可得时点之后是否仍有可交易漂移？ | R4a需公告去重与季报版本；R4b另需分析师预期版本 | 使用公告后共识、最新财报或今天主题标签补齐历史 |

R1 与 R2 构成最先实现的共同基础；R3 用于检验量价行为信号的成本后价值；R4 依数据门槛安排。R1 没有证明轮动之前，也可以仅产出可信的被动与趋势基线。R2 的正则线性和 GBM 使用同一特征、标签、股票池、交易规则与调参预算；不能让复杂模型暗中增加数据或测试次数。

主题／政策 NLP、微盘、全市场宏观状态模型与高频暂缓。暂缓不表示永久否定，含义是其当前证据、数据或执行条件不够支持占用 MVP 预算。新增证据达到既定门槛时，提交里程碑审查并在 [DECISION_LOG.md](DECISION_LOG.md) 记录。

## 7. 可证伪标准与终止条件

### 7.1 共通规则

1. **数据或执行无效：**出现未来信息、幸存者偏差、同收盘偷看、错误规则或未记录调参，实验标为无效。修复后按原登记计划重跑；不得把修复前结果留作收益证据。
2. **经济优势不足：**在预先定义的成本／风险匹配样本外实验中不能达到 [EXPERIMENT_PLAN.md](EXPERIMENT_PLAN.md) 门槛，归档该方向或降为基线。不得通过删年份、换基准或重用最终测试集补救。
3. **证据不足：**置信区间太宽、独立事件太少不等于证明不存在效应，但也不准进入实盘。可等待前瞻数据；追加探索必须成为新登记假设。
4. **复杂模块无增量：**未能超过相同输入的简单基线，删除复杂模块。删除是合格研究结果，不是项目失败。

### 7.2 逐项早期淘汰检查

| ID | 主要可证伪或终止条件 |
|---|---|
| H01 | 优势被行业／规模匹配或 PIT 修复消除；净收益不及同风险基线；无需强行归因成独立 Alpha |
| H02 | 在价值／行业／规模条件下无增量，且不改善预设风险效用；保留为描述变量或删除 |
| H03 | 优势仅来自分红口径漏税、行业偏置或总收益比较不对称；归类为风格配置 |
| H04 | 结果主要来自不可退出微盘、退市漏损失或单次制度红利；停止作为当前收益核心 |
| H05 | 与同 Beta／同平均仓位基准相比没有额外效用；可以保留风险用途但不宣称 Alpha |
| H06 | 统一流通股本和量额口径、控制规模／流动性后效果消失；或不具费用后稳定性 |
| H07 | 方向在独立窗口中不稳定，或只有从大量期限中挑出的单点有效；停止扩大参数搜索 |
| H08 | 残差规格小改即失效、无足够历史估计或仅来自某个风险模型；归档 |
| H09 | 次日成交、无法卖出库存、最低收费和保守滑点加入后不达净收益门槛；优先停止 |
| H10 | 成交量相对价格无独立 OOS 增量，或依赖大范围窗口调优；退回简单价格基线 |
| H11 | 行业分类 PIT／实际 ETF 上市约束后优势消失，或行业排序不及同池静态配置 |
| H12 | 所谓领先关系被非同步交易、不同交易日历或规模／成长暴露解释；停止称板块预测 Alpha |
| H13 | 仅凭已知风格收益历史选出切换规则，后续独立切换事件不足；等待新数据 |
| H14 | 在现金／风险匹配比较和机会成本计入后不改善预设效用；择时模块关闭 |
| H15 | 年报 surprise 实际早已由预告／快报披露，或事件后才出现可用预期；该事件信号无效 |
| H16 | 无法获得原始研报或共识历史版本；不进入回测，不能用人工补估伪造 PIT |
| H17 | 只有同期相关而无滞后预测；AUM 价格变化被误算为净流入；不作交易信号 |
| H18 | 无历史成员／词典版本，或 LLM 表现依赖未来知识；历史研究止步于描述，转前瞻采集 |
| H19 | 固定输入和搜索预算后不超过正则线性；收益依赖少数期或额外换手；删除复杂模型 |
| H20 | 使用平滑后状态或修订值才有效，过滤状态延迟后不及简单趋势／不择时；关闭复杂状态模块 |

## 8. 收益来源必须可审查

每个候选报告至少给出：纯做多净收益、同池基准、风险匹配基准、规模／行业／价值／Beta 暴露、现金比例、换手和成本贡献。多空分组可用于诊断，但不得当成账户可实现收益。某一弱组跑输并不证明强组可在做多中创造同等优势。

对轮动必须分别检验：排序贡献、趋势开关贡献、风险缩放贡献和交互作用。对股票模型必须分别检验：价值、盈利质量、交易特征、中性化、权重优化与 ML 的增量。实验细节由 [EXPERIMENT_PLAN.md](EXPERIMENT_PLAN.md) 统一登记，本文不额外扩张试验空间。

最终允许的结论包含：无优势、成本吞噬、风险溢价而非独立 Alpha、数据不足以及复杂模型无必要。只有证据支持时，才把候选晋级为可执行策略。
