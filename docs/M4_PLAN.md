## A的边界解释与B的判断顺序

原strategy._snapshot采用半开区间`effective_from <= day < effective_to`；本轮保持这一边界，不能误改为结束日也有效。缺上界表示无界，缺可得时点不代表已知。先处理截至查询时已知的版本/纠错和有效起点，再检查结束边界，不能在到期后复活已被替代的旧状态。未来生效记录不得提前授予或撤销当前权限；公告/接收/可得时点原样保存，不改成生效日。冲突拒绝而不按文件行序选一条。

到期状态未知时禁止新增；既有股数、成本和权益继续留账。只有当前可核实规则、交易状态与可成交窗口成立才允许退出，不借旧权限推断未知规则。实际生产语义、限制和反例另由审查记录完整说明。
