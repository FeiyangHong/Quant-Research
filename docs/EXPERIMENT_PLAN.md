## 1 研究问题与四个假设族

- H1/R1：ETF相对排名在相同可交易集与成本下，是否优于同池等权；简单趋势是否增加风险调整后效用？两者分别报告。
- H2/R2：价值+盈利质量是否超过同池、行业/规模匹配基线；质量与非线性是否有独立增量？
- H3/R3：短期残差反转能否在次日执行、成本和尾部库存之后保留净优势？
- H4/R4：首发盈利信息后的漂移是否可交易，而非已在缺口/涨停或先前预告中实现？

每族进入最终检验前只能冻结一个主要交易规则、一个主基准和一个主端点。内部变体仍计入搜索，不能把H1内每个ETF宇宙当独立不计数的机会。R4b需另注册，不借用H4a剩余预算。

## 2 历史区间和锁定方式

优先取得2010-01-01至2026-11-13数据，具体以真实交易日和供应商覆盖为准。2016-01-01之后且规则完整的部分是优先可审计交易区间；更早数据可用于特征暖启动、机制诊断，补齐费用/规则后才能报告确认性净收益。上市不足/行业ETF不存在的年份不补造可交易资产。

| 区间 | 用途 | 边界 |
|---|---|---|
| 2010—2021 | 开发、因子定义检查、按时间walk-forward | 接触过即视作开发数据；早期交易结果受规则完整性限制 |
| 2022—2024 | 固定候选比较与选择验证 | 仍然是验证集，可在预算内选择；不称最终独立测试 |
| 2025-01-01—2026-11-13 | 冻结后的历史holdout | 只开放一次研究审查；若曾看过策略结果标记污染 |
| M1配置签名冻结后的首个交易日起 | 前瞻shadow/paper记录 | 真正未来证据；时点、模型、订单和实际可得数据同时存档 |

今天设计研究时已知道过去发生过哪些大事件。因此历史holdout最多是项目层面未用于调参的留出，不是天然完全未知的未来。登记 known_history、prior_experiments、holdout_access_log；任何重定义都保留原测试失败。

ML采用年度walk-forward：预测年Y之前5个完整年训练、最近1个完整年作内部验证（即训练Y-6至Y-2，验证Y-1），Y年预测。最早可审计预测年为2016；不足暖启动历史的ETF规则不强行训练模型。每年只按预先冻结流程更新；Y年标签必须成熟后才允许成为Y+1等后续轮训练输入。测试窗内预先规定的在线/滚动更新可以发生，但人不能据其表现改特征、超参数网格或窗口。

在训练/验证/测试边界，剔除标签区间跨越边界的训练样本；用于选择超参数的验证标签也必须在下一预测期首个决策前完全成熟，验证年尾部未成熟标签同样purge；最大20日标签至少要覆盖其实际跨度。若组合5/20/60日标签，purging按最长实际跨度调整。embargo用于有训练块位于验证之后的特殊诊断，纯向前切分优先；不机械删掉252日历史特征。全流程按日期切分，同日所有股票属于同一折。

最终集若失败，新假设成为新版本，旧最终集降为已接触历史；新确认性证据来自真正未使用的后续时期，不能更换一个已经看过的漂亮年份充作新测试。

样本末端尚未完整实现的5/20/60日标签不计算对应IC或预测误差，不以0填充；该期间的实际账户NAV仍按可得交易和持仓计价报告。未结束的事件持仓保留，不能为补全标签偷看截止日之后的数据。

## 3 主基准与公平比较

1. 外部背景：沪深300、中证500、中证1000、创业板及可获得的全市场全收益指数。科创/北证用于研究和代理暴露解释。不能用价格指数比较含股息策略。
2. 可执行被动：真实可买ETF买入持有，计分红、成本和整数份额；无ETF的早期时段不得拼接假产品。
3. 同池等权：每个策略相同资格、再平衡与成本下的对照。
4. 简单因子：F01单独、质量单独、固定组合；同样交易约束。
5. 简单趋势：固定200日均线与不择时；现金/波动预算匹配对照。

风险匹配基线在开发/验证期确定规则，再对未来实施；不以整个测试期的实现波动反向缩放成“可交易”基准。可另报事后波动匹配作为描述，但必须标注 ex-post。择时方案的降回撤如果由低平均仓位完全解释，应表述为配置效用而非时点预测Alpha。

### 3.1 确认性主对照

| 假设族 | 默认主要比较 | 可以支持的主要命题 |
|---|---|---|
| H1/R1 | 冻结的排名组合 vs 同一ETF池等权，趋势开关和波动缩放完全相同 | 排名在给定风险规则下是否带来净经济增量 |
| H2/R2 | 固定价值+盈利质量规则 vs F01价值单因子，沿用相同资格/30只/缓冲/行业/执行规则 | 加入这两个质量项是否超过价值基线 |
| H3/R3 | 冻结的残差反转 vs 同一资格池等权周度组合，风险缩放规则相同 | 该反转组合是否超过同池配置 |
| H4/R4a | 事件组合 vs 策略规范冻结的历史行业/规模/Beta/前期收益匹配组合 | 首发信息事件是否有可交易的相对漂移 |

R1在已注册的两个宇宙和模块设置内可用开发/验证选择，但进入最终集前只能冻结一个主要比较，其余为辅助。R2的线性/树增量与R1趋势效用本轮默认属于辅助分析；若改为主命题，必须在打开最终集前注册并更新本表，不能事后替换。四档本金必须预定一个主要部署档，不能在最终结果中挑最显著档位。所有辅助指标、变体和切片仍展示，但不据其未调整p值另作确认性主张。

## 5 必须执行的实验矩阵

| 检验 | 主问题 | 具体实现 |
|---|---|---|
| 消融 | 哪个模块有增量 | 选择/趋势/风险缩放/质量/树模型分别开关 |
| 成本压力 | 毛收益是否足够 | 真实历史税费不变；佣金/滑点/冲击1×/2×/3×分项报告 |
| 执行时延 | 信号是否太短命 | 次日与额外1日；日期不明公告额外1日；锁仓1—3日压力 |
| 容量 | 四档本金是否可实现 | 整手、现金、ADV1%、分钟参与5%与1%、部分成交 |
| 微盘/股票池 | 是否只是样本选择 | 排除底部0/20/30/40%对照；主板独立；行业/市值权重 |
| 参数稳定性 | 是否尖峰最优 | 固定相邻窗，不继续微调；所有结果展示 |
| 跨阶段 | 是否只赢某个周期 | 按自然年、预定义政策制度断点、因果趋势/波动状态；另列危机诊断 |
| 分红/公司行为 | 是否会计伪收益 | 股息、税追扣、配股/拆合股/ETF分红、退市清偿逐笔回放 |
| 复杂度 | ML是否值得 | 同特征、同构建、同成本、同预算；规则→线性→树 |
| 泄漏 | 时间是否可信 | 数据前缀不变性、延迟1日、随机标签/乱序仅作负对照 |
| 独立测试 | 是否外推 | 冻结历史留出及持续前瞻；所有模型同时评估 |

状态切片可以事后解释，但不能据事后牛熊标签选择当时的持仓。2015等不在可审计期的危机只有补齐制度后才可作交易压力结果，否则只作机制/数据诊断。删除最盈利一年后增量方向是否保留、利润是否由少数交易贡献，都要报告；不能仅因单年贡献较大自动断言造假。

## 6 统计与评价

每日NAV=总自有现金（可用+委托冻结现金，不含未成交卖单的预期回款）+全部风险持仓的明示估值+应收股息及其他可核实权益−应付费用/税负。可用现金只约束下单，不代替总现金；可卖股数不代替全部风险持仓。下单冻结/撤单解冻不改变NAV。

估值依次采用可核实交易价、当时可获得的独立估值；停牌/长期无报价可暂用末次价但必须标stale/unpriced，并单独给行业代理下跌和固定减值压力，不能靠陈旧价格声明低波/低回撤。退市且无可核实可收回价值时，确认性主路径采用审慎零估值，同时在权益台账保留后续回收权利；有实际清偿再入账。这不是断言经济价值必然为零。列示不同回收假设敏感性；未知权益不得永久按最后交易价掩盖损失。期末另列按当时清算假设的潜在红利税，不让延后扣税掩盖可兑现净值。

- CAGR按真实日历跨度计算；波动、Sharpe用明确交易日年化因子与可获得现金基线；同时给不做平方根放大的序列相关稳健评估。
- Sortino目标回报明确为现金基线；Calmar报告样本区间；最大回撤与回撤持续时间、尾部ES、最差日/月和流动性锁仓分开列。
- 主端点是同一日期的 d_t=r_candidate,net(t)-r_baseline,net(t) 的算术均值。此处net已扣交易费用、滑点、冲击与账户税负，尚未扣作为门槛的增量固定数据/运行费用。主检验 H0:E[d_t]≤h，备择为大于h；h=ΔC/(N0×252)，ΔC为候选相对基准的年度增量固定费用、N0为预注册主要本金。该式是事前经济门槛，真实费用支付另用账户账簿情景报告；若该费用已经从两条NAV扣除，则h=0，禁止重复扣费。缺真实报价时经济确认状态为BLOCKED_HURDLE，不把未知费用伪设为0。净Sharpe、IR和回撤为辅助，不挑最好指标。
- 每族在M0注册claim_type，默认economic_increment，以有效单侧p_net为该族唯一主p值。若预先选择economic_and_factor_alpha，则同时要求E[d_t]>h与预注册回归 d_t-h=alpha+beta'F_t+error_t 的alpha>0，以p_family=max(p_net,p_alpha)进行交并检验。这只支持“净经济增量及指定因子模型下正截距”，不证明相对所有潜在风险独立或因果技能。只做一组四族Holm；不能先对四个p_net检验一轮、再对四个复合p另检验一轮并声称全部结论仍受总体5%控制。
- 因子模型预注册市场、规模、价值及可复现中国交易/盈利风险因子的单一主规格；若CH-3/CH-4等不能可靠复制，明确缺口，不能用随手代理得出“独立Alpha”。可以列少量预定规格作敏感性，但不能选最有利者。economic_increment模式下因子回归只作解释性诊断；要提出其确认性主张需预先采用上述联合命题或另行登记调整。
- 每日RankIC先在横截面计算，再沿时间分析；标签重叠和股票共振使N股票×T日不是NT个独立观测。收益组、IC与事件研究都校正时间/共同冲击依赖。
- 采用按日期同步的block bootstrap，所有策略/因子/基准一起抽同一日期块；主块长60交易日，20/120日作固定敏感性，至少5,000次重复。主均值检验在边界E[d_t]=h下中心化并采用事前固定的学生化/依赖稳健实现；alpha推断同样保留时间依赖。不能把未经零假设中心化的bootstrap负值比例当p值。事件另处理发行人重复事件聚类，HAC作交叉检查；短样本和非平稳情况下披露近似误差。
- 最终固定四假设族的一组预注册主p值使用Holm家族错误率目标5%，有效性以前述各p值有效为前提；未就绪或数据不足的家族保留且p=1，不能事后缩小家族。探索性因子FDR10%仅作筛选，并说明相关依赖假设，必要时采用更保守控制。所有历史尝试要进入搜索记录，不能只计最终4个赢家。
- DSR/PBO是补充诊断，输入需包含真实搜索次数/相关性和完整配置表现；不作为“超过阈值即可实盘”的自动通行证。

同时报告95%不确定性区间、最小可检测效应与统计功效局限。短样本或高度相关市场年份可能不足以给窄区间；此时标签为INCONCLUSIVE。不要靠增加几千只股票虚增有效样本数。

## 7 成功、失败和证据不足

### 工程与数据硬门槛

已测试的关键泄漏/会计/权限用例全部通过；无未解释的净值不守恒；关键规则、成交日/时间、股票与基金公司行为、费用归属明确。无法成交、缺失和排除原因逐条可追溯。日线筛查不能通过实盘执行门槛。

### 研究候选 PROMISING

同风险/同池对照的样本外净增量点估计为正；不依赖不合格数据或不可成交；2×非税成本下方向仍可接受；多个年度/滚动窗口具有可解释稳定性，敏感性不是孤立峰值；四档资金中至少预先选择的主要部署档可实施。若置信区间仍跨零，只能进入继续采集/模拟的候选，不能称统计证实。

### 可支持的确认性结论

冻结候选的主命题通过唯一一组Holm调整后的预注册检验，并且归因、尾部、成交与成本门槛通过。另报95%区间及其是否为边际或同时区间；普通边际95%区间不替代多重检验。经济门槛按第6节扣候选相对基准的增量固定费用，不能把共享费用重复计算；同时展示全部固定数据/运行成本对账户总收益的负担。未知报价不伪设为零。

这仍不是未来收益保证。若主要收益可被风格解释，可以作为透明风险溢价配置方案报告，但不能更名为选股Alpha。若趋势只改善风险效用，也按其实际贡献保留。

### 失败或暂停

- FAILED_DATA/ENGINE：PIT错误、权限/现金/规则/成交错误；暂停相关结果，不讨论策略是否无效。
- RETIRED_ECONOMIC：保守交易成本已吞掉优势、主要部署档无法分散、依赖不可获得数据或不可成交价格。
- INCONCLUSIVE：区间太宽、样本或独立市场阶段不足；不显著不是证明不存在。
- RETIRED_HYPOTHESIS：充分检验后不支持预注册机制，或只有违反约束/变更收益来源才能“救回”。

不设凭空的年化收益、Sharpe或最大回撤业绩目标。RISK_POLICY的风险预算属于设计约束，不是预计成绩。所有否定和未完成结果一并交付。

## 8 归因与汇报

每个run交付 metrics.json、nav.parquet、positions.parquet、orders.parquet、fills.parquet、rejected_orders.parquet、costs.parquet、exposure.parquet、uncertainty.json 和 report.md（实际格式可按项目栈等价实现）。要能从交易账本重新构造净值，而不是只存最后一条曲线。

报告至少包括年度/月度分布、交易与风险统计、市场/风格/行业归因、现金与择时贡献、选股增量、无法成交及费用损失、数据缺口和相同区间基准。收益归因分层展示，不把高度重叠的解释简单求和。
