## 验证结果

执行 `.venv\Scripts\python.exe -m pytest tests/test_data.py -q`，结果 **20 passed**。重点用例：

- 相同seed复现、空表schema保留、快照hash篡改拒绝、不同内容不得覆盖旧版本。
- 未来修订加入不改变早期查询；切换到修订可用时点后才读取修订；重复版本键与同时间歧义拒绝。
- 时区不可省略；21:00之后及海外未来收盘不可提前可用；日期精度公告在下一交易日21:00生效，压力情景额外延迟一日。
- 退市前知识状态不含未来退市日；退市后主表身份仍保留；退市后不补价格。
- 分红/拆分的原始价与逐日总收益关系；缺记录不填0/冒充停牌；无穷/缺失价格、非法OHLC、字符串权限拒绝。
- synthetic永不升级为performance_evidence；真实来源、许可、覆盖/PIT证据缺失时默认加载失败；隔离读取仍为BLOCKED_DATA。

根协调任务负责生成运行级manifest、代码/环境绑定、全套测试与实验review packet。本审计不提前声称集成测试或真实策略实验已通过。
